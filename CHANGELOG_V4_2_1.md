# HALARYK V4.2.1 — patch correctif

- Refonte mobile plus compacte : sections moins hautes, rubans horizontaux pour les séries de cartes, ludothèque en cartes paysage compactes.
- Menu mobile remplacé par un panneau plein écran stable et organisé.
- Réputation mobile fortement raccourcie : rangs, explications et classements défilent horizontalement ; seuls les 5 premiers profils de chaque classement sont visibles sur téléphone.
- Ludothèque : note visible directement sur chaque carte, y compris « Non noté ».
- Statuts admin simplifiés à En cours / Terminé / À venir ; les anciens statuts sont affichés comme À venir jusqu’à réenregistrement.
- Les actualisations IGDB ne remplacent plus le résumé public. Le résumé devient un texte éditorial court (520 caractères max), idéalement en français.
- Les résumés trop longs sont condensés côté public pour préserver la lisibilité.
- CSP ajustée pour les source maps jsDelivr ; les avertissements propres aux embeds Twitch/adblock peuvent encore apparaître et ne viennent pas du site.
